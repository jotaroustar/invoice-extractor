## ✨ 核心特性

### 🟢 本地校验引擎（完全免费，零数据上传）
* **金额自动核对**：内置自动计算规则（不含税金额 + 税额 ≈ 价税合计），误差超 0.05 元即触发高亮警示。
* **规则合规审查**：
  * **税号校验**：自动识别 15/17/18/20 位长度，不符合规范即刻标红。
  * **主体一致性**：自动匹配发票抬头与报销主体名称，不一致自动标黄提醒。
  * **报销时效监测**：根据设定的时效天数（默认 90 天），自动筛出超期发票。
  * **品类合规控制**：支持自定义“黑名单”关键词（如烟/酒/KTV/棋牌室），一键识别违规消费。
  * **发票查重**：在当前批次内自动对比发票号码，防止重复报销。

### 🔵 AI 提取模式（BYOK·需 API Key）
* **结构化提取**：自动从发票代码、号码、日期、购销双方税号、商品条目到价税金额，实现全字段自动化拆解。
* **智能模型自动调度**：根据发票文本长度自动切换模型（`gpt-4o-mini` 极速模式 vs `deepseek-chat` 精准模式），在响应速度与提取精度间取得极致平衡。
* **流式进度反馈**：采用 SSE 流式解析技术，从发票号码识别到金额解析，实时点亮提取进度标签，告别提交后的干等体验。
* **即时交互式修正**：所有提取字段均支持即时在线编辑，修改后本地校验引擎会自动实时重算，结果立即可见。

## 🚀 快速使用

### 方式一：本地直接运行（推荐）
1. 将以下三个文件放入**同一文件夹**内：
   - `index.html` (主程序)
   - `pdf.min.js` (PDF.js 核心库)
   - `pdf.worker.min.js` (PDF 解析引擎)
2. 双击 `index.html` 即可运行（因涉及 PDF 解析，必须确保三个文件同目录）。

## 🛡️ 隐私与数据安全承诺

* **核心校验本地化**：金额核对、税号位检查、报销时效检测等所有核心校验均在浏览器内存内完成，零数据流出。
* **PDF 本地解析**：利用 `pdf.js` 在本地浏览器环境提取 PDF 文本层，PDF 原始文件绝不上传至任何服务器。
* **安全网关转发**：在 AI 模式下，文本内容经网关加密转发至模型服务商，网关不记录、不持久化任何对话内容。
* **API Key 隔离**：所有的 API Key 仅加密存于本地浏览器 `localStorage`，系统不参与存储。
