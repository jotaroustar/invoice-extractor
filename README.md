# 报销单/发票提取器

批量提取发票关键字段，本地校验金额与税号，一键生成报销清单。支持文本粘贴与PDF上传，本地校验完全免费，AI提取需自备API Key。

`HTML 文件` `Platform PDF | 文本粘贴` `本地校验免费` `AI BYOK`

---

## 🚀 快速使用

### 方式一：直接下载使用

下载以下三个文件放在**同一目录**，用浏览器打开 `index.html` 即可（缺任意一个PDF解析会报错）：

```
index.html
pdf.min.js
pdf.worker.min.js
```

- 主要地址：https://jotarou.com/tools/invoice-extractor/
- 备用地址：https://jotaroustar.github.io/invoice-extractor

## ⚡ 功能特性

### 🟢 免费本地模式（无需API Key）

场景化批量管理

不需要逐张登记，拖文件或Ctrl+V粘贴即可入批次：

| 操作 | 效果 |
|---|---|
| 🖱️ 拖拽PDF / 点击选择 | 自动识别为发票条目，本地提取文本层 |
| ⌨️ Ctrl+V 粘贴文字 | 自动识别为纯文本条目，无需切换标签页 |
| 📋 自查清单 | 抬头、时效、品类、税号等5项报销防坑要点 |

本地校验引擎（全部不调用AI，纯前端计算）

| 校验项 | 规则 |
|---|---|
| 金额自核对 | 不含税金额 + 税额 ≈ 价税合计，误差超0.05元标红 |
| 税号位数 | 长度不在15/17/18/20位时标红提醒 |
| 抬头比对 | 购买方名称与填写的"报销主体名称"不一致标黄 |
| 报销时效 | 开票日期距今超过设定天数（默认90天）标黄 |
| 品类黑名单 | 商品/服务名称命中关键词（烟/酒/KTV等）标黄 |
| 发票号查重 | 同批次内发票号重复出现标红 |

工作流程：拖入/粘贴发票 → 提取全部 → 核对标红标黄项 → 导出清单

---

### 🔵 AI提取模式（BYOK·需 API Key）

发票文本 → 结构化字段

工具自动提取：发票代码、发票号码、开票日期、销售方/购买方名称及税号、商品服务名称、不含税金额、税额、价税合计、税率、发票类型，并标注备注异常。

模型按文本长度自动切换

| 文本量 | 模型 | 标签 |
|---|---|---|
| ≤8000字 | gpt-4o-mini | ⚡ 极速模式 |
| >8000字 | deepseek-chat | 🎯 精准模式 |

流式提取+进度标签

提取过程实时显示AI输出内容，发票号码/销售方/金额/发票类型识别到对应字段时进度标签自动点亮，不是提交后干等结果。

JSON解析失败兜底

模型偶尔返回格式异常时，不会直接报错卡死，原始输出会完整展示，方便人工核对。

字段可直接编辑修正

AI识别有误或发票本身字迹模糊时，结果字段是可编辑输入框，改完本地校验实时重算，不是只读展示。

## 🧩 用户体验细节

- 深色/浅色模式：跟随手动切换，保护长期使用的打工人的眼睛
- 一键脱敏：扫描动画处理原文中的手机号/身份证号/银行卡号，处理后不可逆，截图分享前更安心

- 三种导出格式：CSV（带BOM，Excel直接打开不乱码）、Markdown表格、纯文本清单

## 🔒 隐私说明

- 本地校验：金额核对、税号位数、查重等全部在浏览器本地完成，零数据上传
- PDF解析：文件本身不上传，pdf.js在浏览器本地提取文本层，仅文本内容会经AI模式发送
- AI模式：通过jotarou.com API网关转发至大模型服务商，网关不持久化对话内容
- API Key 存储：仅存于你的浏览器本地（localStorage），不经过本工具服务器存储
